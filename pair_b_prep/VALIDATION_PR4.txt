CONFIRMED BUG
StockfishEvaluator.children_values receives a Board containing seven prior moves.
For candidate h8g8, preserving the move stack yields a threefold repetition draw.
Expected White-view score: 0. Actual score: +1, marked as rule-decided.
Cause: child = board.copy(stack=False) discards history before rule_value(child).
See repetition.json and check_repetition.py for the complete reproducer.
This is the existing issue reported by Teal, independently reproduced here.
MaterialEvaluator's public method accepts only FEN; it returns -1 for the same
move from Black's perspective because FEN cannot represent repetition history.
That API limitation is distinct from dropping a history already supplied as Board.
Search integration must evaluate history-dependent terminal rules before FEN-only
leaf calls. Colin should fix the internal Board path and add regression coverage.
