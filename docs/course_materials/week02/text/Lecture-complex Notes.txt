Example: Sussman Anomaly
Consider three blocks A, B, and C with the following:
• Initial State:
     • Block C is on Block A (on(C, A)).
     • Block A is on the table.
     • Block B is on the table (onTable(B)).
• Goal State:
     • Block A on Block B (on(A, B)).
     • Block B on Block C (on(B, C)).
               Original source: Sussman, G. J. (1975). A Computer Model of Skill Acquisition. Elsevier.

Example: Sussman Anomaly
Sequence 1: Achieving on(A, B) first, then on(B, C)
1. Movetotable(C, A) – Move Block C from Block A to the table.
2. Move(A, table, B) – Move Block A from the table to Block B.
     • Subgoal Achieved: on(A, B).
3.     Movetotable(A, B) – Undo the subgoal on(A, B) by moving Block A from
       Block B back to the table to clear B.
4.     Move(B, table, C) – Move Block B from the table to Block C.
     • Subgoal Achieved: on(B, C).
5.     Move(A, table, B) – Finally, move Block A from the table to Block B again.
     • Final State: on(A, B) and on(B, C) achieved.

Example: Sussman Anomaly
Observations:
• In both sequences, achieving one goal required undoing previously
  achieved subgoals, which exemplifies Sussman Anomaly. Specifically:
     • In Sequence 1, the subgoal on(A, B) was undone in Step 3 to achieve on(B, C).
     • In Sequence 2, the subgoal on(B, C) was undone in Step 2, and on(A, B) was
       undone in Step 5 to rearrange the blocks.
• These steps highlight the interdependencies and conflicts between
  subgoals, demonstrating the complexity and inefficiency in achieving all
  goals without having to backtrack and redo certain actions.


Real World Planning and Acting                                                         5
Example: Sussman Anomaly
• What is the problem with independent subgoals?
     • Moving two blocks to specific positions may require a sequence that
       undoes one goal to achieve another.
• Serializable Subgoals:
     • A planning approach where subgoals are achieved in a specific
       sequence without conflict.
     • Ensures each subgoal is completed without undoing previously
       achieved goals.
     • Helps avoid issues like Sussman Anomaly.
