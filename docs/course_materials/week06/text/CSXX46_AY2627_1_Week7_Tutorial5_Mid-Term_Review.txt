Problem 3: Preference Modelling
Alex is given the choice between two games:

    - Game 1: a fair coin is flipped, and if it comes up heads, Alex receives $100. If the coin
      comes up tails, Alex receives nothing.

    - Game 2: a fair coin is flipped twice. Each time the coin comes up heads, Alex receives $50,
      and Alex receives nothing for each coin flip that comes up tails.

Alex prefers Game 2 to Game 1. After that, Alex is given two choices: Game 1 and directly re-
ceive $50. Argue that Alex would prefer to receive $50 compared to being allowed to participate
in Game 1.

Problem 5: Markov Decision Process
Consider a robot navigating a 10 × 10 grid world. At each time step spent in a non-goal cell, the
robot incurs a cost of 0.05. The cell (10, 10) is the goal state and provides a reward of +100. The
game will end whenever the robot reaches the goal cell. The robot may select one of four actions:
UP, DOWN, LEFT, or RIGHT. Given a selected action, the robot moves in the intended direction
with probability 0.8, or in either of the two directions orthogonal to the intended direction with
probability 0.1 each. The duration of each movement is stochastic. Suppose the robot selects an
action at time t:

    • With probability 0.5, the movement takes one time step and is completed at time t + 1.

    • With probability 0.5, the movement is delayed by one additional time step. In this case, the
      robot remains in its current cell at time t + 1, and the movement is completed at time t + 2.

The robot may select a new action only after its previously selected action has been completed.
Thus, if an action is still in progress at time t + 1, the robot must wait and cannot select another
action at that time. Its next decision is made only when the pending movement has finished. Model
this situation as a Markov Decision Process. Clearly specify the state space, action space, transition
probabilities, and reward function. Ensure that the state representation accounts for whether the
robot has an unfinished action. Optional: Determine the optimal policy at time t = 2, and state the
method used to obtain it.
