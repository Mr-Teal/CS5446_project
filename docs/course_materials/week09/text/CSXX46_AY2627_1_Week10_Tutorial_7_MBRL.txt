Problem 2: When the Conditional Mean Is Misleading
An autonomous vehicle must pass an obstacle. From the same state-action pair (s, a), the true next
lateral position is either
                                 s′L = −1 or s′R = +1,
with probability 0.5 each. Position 0 lies inside the obstacle.

  (a) If a deterministic dynamics model is trained with squared-error loss, what next position will
      it tend to predict? Why can this be problematic?

  (b) A probabilistic model instead represents both outcomes. Suppose both transitions give re-
      ward 1, U (s′L ) = 4, U (s′R ) = 8, and γ = 0.9. Compute the expected one-step backup for
      taking action a.

  (c) If sampling-based planning draws just one next state from the model, what backup value is
      obtained for each possible sample? What is their expectation?

  (d) What does this example show about deterministic and stochastic dynamics models?

Problem 3: Background and Decision-Time Planning
A rover has learned a model of its environment. Consider three ways to use it: Q-planning, Monte
Carlo Tree Search (MCTS), and Model Predictive Control (MPC).

  (a) Which method is primarily background planning, and which are decision-time planning?
      Briefly explain the distinction.

  (b) At the current state, an MPC planner considers two action sequences over horizon H = 2.
      Their predicted rewards are
                                      A : (3, 4),    B : (4, 2),
      with γ = 0.9. Which sequence has the larger predicted discounted return?

  (c) Why does MPC execute only the first action of the selected sequence and then replan?

  (d) MuZero uses MCTS in a learned latent state space and does not reconstruct future observa-
      tions. Why can such a model still be useful for planning?
