1.3     Part C

Reason for difference:

      • Part A (full model / expectation backup): It computes an exact, expectation-based Bellman update
        across all possible next-states weighted by their transition probabilities Pη (s′ | s, a). And it has zero
        sample variance relative to the model.

      • Part B (sample-based Q-Planning / sample backup): It uses stochastic sampling to draw a single
        transition (s2 ). Because s2 carries a negative reward and lower utility (U(s2 ) = 2 vs U(s1 ) = 6),
        this single sample introduces high variance.

      • Sample-based updates have lower computational cost per step, but higher variance. With a large
        amount of random samples, the expected update of part B can converge to part A.


1.4     Part D

Dyna-Q combines real environment experience, model learning, and sample-based planning in a unified
architecture:

    1. Direct RL: Executes action a in real environment state s, observes real r, s′ , and updates Q(s, a)
       directly.

    2. Model learning: Updates the learned model Pη , Rη using the real experience (s, a, r, s′ ).

    3. Planning: Performs K simulated Q-planning steps per real step. This involves uniformly sampling
       previously visited state-action pairs (ssim , asim ) from the learned model, generating simulated next-
       states, and updating their Q-values.

2.4     Part D

    1. Limits of deterministic models: Deterministic models predict the expected next state, which col-
       lapses multimodal distributions into an invalid or unsafe mean.
    2. Advantages of stochastic dynamics models: Probabilistic or sample-based models preserve distinct
       valid futures and evaluate outcomes in value space (E[V (s′ )]). They represent stochastic environ-
       ments accurately to prevent catastrophic averaging and ensure safe, robust planning.


3     Problem 3

3.1     Part A

      • Q-Planning: Background Planning. It uses the model offline / in the background to update general
        value functions Q(s, a) across all states to improve policy readiness before action selection.
      • MCTS and MPC: Decision-Time Planning. They use the current state st at decision time to evaluate
        trajectory trees or lookahead rollout sequences before executing an action.
      • Distinction: Background planning updates global value functions over the state space asynchronously.
        Decision-time planning computes local trajectory rollouts specifically for the current state to choose
        the immediate best action.


3.2     Part B

MPC sequence discounted return (H = 2, γ = 0.9):

      • Sequence A (3, 4):
                                       GA = r0 + γ r1 = 3 + 0.9 × 4 = 3 + 3.6 = 6.6
      • Sequence B (4, 2):
                                       GB = r0 + γ r1 = 4 + 0.9 × 2 = 4 + 1.8 = 5.8

Sequence A is preferred as GA (6.6) > GB (5.8).


3.3     Part C

    1. Model imperfection & unmodeled disturbance: Real environments can deviate from model predic-
       tions over time, and executing full long sequences accumulates drift.
    2. Receding horizon control: Re-planning at st+1 incorporates actual observed state feedback, updat-
       ing future trajectories with fresher data over an extended horizon window.

4.3     Part C

The terminal Q-value acts as a boostrap estimator for states beyond the finite planning horizon H. It
estimates the expected cumulative future return. So the planer can account for long-term consequences
without computationally costly long rollouts, effectively truncating planning depth while maintaining
infinite-horizon accuracy.
