# CS5446 course materials (AY2026/27 Sem 1)

The official lecture slides, tutorials, assignment handouts and guidelines posted on Canvas, kept here so that team members (and their AI assistants) can look up the course curriculum while writing the report.

These are the lecturer's copyrighted materials, shared here for enrolled team members only. Keep this repo private and do not redistribute them.

## Layout

- `weekNN/` holds the PDFs exactly as posted on Canvas, grouped by the Canvas week they were posted in. Nothing was posted under Week 8 on Canvas, so there is no `week08/`.
- `weekNN/text/` holds a plain-text extract of each PDF (`pdftotext -layout`), for searching with grep or for feeding to an AI tool. Slides with mostly figures or equations extract imperfectly, so check the PDF when in doubt.
- Two PDFs are scanned images with no text layer, so their extracts are empty: `week06/Tutorial5_Team8.pdf` and `week09/Lecture-rl-model-based-addendum.pdf`.
- The `TutorialN_TeamNN.pdf` files are the team answers the teaching team posted as tutorial solutions.
- Not included: the assignment code packages (`Assignment1-Programming-Package.zip`, `CSXX46A2-Student.zip`).
