Instabilities in Approximate Utility Learning
• The Deadly Triad
    • Function approximation
         • Required in large state spaces (e.g., linear models, deep networks)
         • Updates to one state/action change many others
    • Bootstrapping
         • Utility estimates updated using other learned estimates (e.g., TD) instead of full returns.
         • Targets are moving because they depend on the same parameters you’re learning.
    • Off-policy learning
         • Learning from transitions not generated by the policy being evaluated
         • The data distribution does not match the one your target policy will induce.
•   Individually each item is fine, but when all three appear together learning can become
    unstable or even diverge.
•   Classic example: Baird’s counterexample (linear function approx + off-policy TD) diverges.

Catastrophic Forgetting
• What happens:
    • Agent forgets earlier parts of state space
    • Utility estimates degrade in rarely visited regions
• When it happens:
    • Over-training with function approximation
    • Lack of coverage during exploration
• Solution: Experience Replay
    • Store and reuse past transitions
    • Helps maintain accurate utility across all regions
