Solving Sequential Decision Problem
• Decision Problem or Model
     • Appropriate abstraction of states, actions, uncertain effects, and goals (wrt costs and
       values or preferences) and time horizon + observations (through sensing)
• Decision Algorithm
     • Input: a problem
     • Output: an optimal solution over time horizon
• Decision Solution
     • An action sequence or solution from an initial state to the goal state(s)
          • An optimal action sequence; OR
          • An optimal policy that specifies “best” action in each state wrt to costs or values or preferences
     • (Optional) A goal state that satisfies certain properties
