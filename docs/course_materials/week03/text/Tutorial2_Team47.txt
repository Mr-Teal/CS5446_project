1.2      Part B
Suppose agent 1 prefers A over B:


                                            U1 (A) ↓ U2 (B)

    Substituting U1 with the given expression:

                                     k1 U2 (A) + k2 ↓ k1 U2 (B) + k2
                                          k1 U2 (A) ↓ k1 U2 (B)
                                            U2 (A) ↓ U2 (B)

    In the last line, the inequality direction is preserved since k1 > 0. From the expression above,
it shows that agent 1 prefers A over B if and only if agent 2 prefers A over B. The same goes for
the situation when U1 (A) = U2 (B). Thus, both agents have the same preferences.

For the multi-turn lottery’s probability of winning $4000 to be the same as that of D:

                                        1 ≃ p = 0.25

                      D = [p : B, (1 ↘ p) : $0] = [0.25 : B, 0.75 : $0]
