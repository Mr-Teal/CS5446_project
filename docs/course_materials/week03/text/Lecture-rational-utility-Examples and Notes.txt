Example: Panda’s Lunch Choice
Partially Observable Environments
• Setup
     • Panda Lulu chooses between Bamboo Grove and Berry Bush, but can't see the grove from her location.
     • Actions: Bamboo Grove (risky) vs Berry Bush (sure 4).
     • Prior over grove state:
       𝑃 𝐵 = 0.5 (bamboo present), 𝑃 ¬𝐵 = 0.5 (empty).
     • Utilities if Lulu goes to the grove: 𝑈 = 10 if 𝐵; 𝑈 = 0 if ¬𝐵.
• Observation:
     • Lulu hears rustling near the grove. Observation 𝑂 ∈ rustling no rustling before choosing. This could mean:
     • Wind in the leaves — bamboo still there, happens 20% of the time if bamboo is present
     • Monkeys eating bamboo — bamboo already gone, happens 60% of the time if bamboo is absent:
     • Likelihoods (rustling more likely when grove is empty—monkeys):
       𝑃 𝑂 = rustling ∣ 𝐵 = 0.2, 𝑃 𝑂 = rustling ∣ ¬𝐵 = 0.6.
• Takeaways:
     • Belief updating (Bayes) → new posteriors → new EUs → new choice.
     • Same prior and utilities can yield different optimal actions depending on the observation.

Certainty Equivalent
• Certainty Equivalent (CE)
     • Fixed amount of money equivalent to a given situation involving uncertainty
     • Value agent accepts in lieu of the lottery
• Example:
     • You are faced with the following lottery:
          • Win            $2000 with probability   0.5    Expected Monetary Value
          • Lose           $20   with probability   0.5          EMV = $990
     • How much are you willing to sell the lottery for?
     • This amount, say $𝑋, is the least that you would accept for the lottery, then
       the lottery must be equivalent in your mind to a sure $𝑋

Expected Utility Theorem: Proof
• [Proof Sketch]:
     • An orderable, transitive preference relation satisfies continuity and
       substitutability if and only if it admits an expected utility
       representation.
          • Based on Levin, Jonathan. Choice Under Uncertainy. Lecture notes, 2006.

Example: Martian Adventures
• Scenario:
     • Mars Base is considering deploying a new tool for Persy the Mars Rover to collect and analyze
       Martian rock samples:
     • Two different power sources: Solar Power and Battery Power.
     • Both power designs have different energy consumption rates and development time.
     • Success rate for either design working efficiently in the harsh Martian environment is uncertain.
     • Only one design can be deployed at a time due to payload constraints on the resupply ships.
     • If either design doesn't work optimally once deployed, a new, modified version may be sent in the
       next resupply mission, but this means waiting longer and it still doesn’t guarantee success.
• Two stage decision problem:
     • Decide on which power design to deploy: Solar, Battery, or neither (if risk is too high).
     • If the tool fails, decide whether to send a modified version or to abort the mission objective.

Basic Elements of a Decision Model
• Decision nodes
     • Decision points with several choices or alternatives
• Chance nodes
     • Uncertain or chance events with several outcomes
• Value or utility nodes
     • Deterministic monetary value or utility functions
     • Measure desirability of final objectives
• Probabilistic dependencies
     • Represent conditional dependence of chance events
• Informational dependencies
     • Represent information available at decision points
