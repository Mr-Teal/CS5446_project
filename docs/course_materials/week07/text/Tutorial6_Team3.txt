(a)
Assuming all combinations of variable values are valid, the state space contains

Tabular value iteration must update every state. Since each action has two possible successor
outcomes, one Bellman sweep costs O(AnM ), and the value table requires O(nM ) memory.

For fixed n > 1, these costs grow exponentially with M .

Thus, ordinary tabular value iteration is generally not efficient as M grows.

When D is a small fixed constant and A is bounded, online search examines only a limited

                                              O(T D)

Under the usual rule of adding at most one new state node per trial, the stored search tree has
at most T + 1 state nodes, so its node and edge counts are O(T ).

If an implementation inserts every new node encountered along each sampled path, the tree-
size upper bound is instead O(T D). Therefore, tree storage depends on the expansion rule,
while the total number of simulated transitions s bounded by T D .


(d)
  1. Selection: Traverse the existing tree from the root using a tree policy such as UCT. Choose
      actions using stored statistics and sample stochastic outcomes from the MDP transition
      model.

  2. Expansion: Add a new child for an unexplored action or outcome branch

  3. Simulation: Follow a default rollout policy from the new node until termination or the depth
     limit, obtaining a return sample

  4. Backpropagation: Update visit counts and average return estimates along the selected path,
     using the appropriate return from each depth

The selection phase applies the exploration-exploitation rule and reuses past statistics to guide
search. Backpropagation updates those accumulated statistics for later trials.

Problem 3: Imitation Learning with Persy the Mars Rover

(a)
A feature-based softmax policy is preferable when the state space is large or continuous. With d
features, it uses O(d∣A∣) weights, whereas a tabular policy requires O(∣S∣∣A∣) storage. Shared
weights also allow demonstrations in one state to inform decisions in other states with similar
features, improving sample efficiency and generalization.

The normalized policy is

                                               exp(θa⊤ f (s))
                                πθ (a ∣ s) =                     .
                                             ∑b∈A exp(θb⊤ f (s))

Softmax produces a valid action distribution and can be trained by minimizing the negative log-
likelihood of expert actions. Its effectiveness depends on whether the features and model class
adequately represent the expert's behavior.


(b)
Behavioral cloning is trained on expert-visited states, but deployment produces states visited by
the learned policy. An early mistake can move Persy into unfamiliar terrain, increasing
subsequent errors.

DAgger repeatedly executes the current policy, queries the expert for actions at the visited
states, aggregates these labeled examples with earlier data, and retrains. Training therefore
covers states the learner actually encounters, including states reached after mistakes, reducing
distribution shift. Expert labels, rather than the learner's own actions, provide the targets.


(c)
No. Human demonstrations are a useful starting point, because they provide expert guidance for
safe navigation and reduce the need for potentially dangerous trial and error. However, I would
not rely on behavioral cloning from Earth-based demonstrations alone. Differences in terrain,
gravity, and rover–soil interactions may cause a domain shift between training on Earth and
deployment on Mars. Persy may therefore encounter out-of-distribution states for which it has
not learned reliable actions. Besides, the same action may have different consequences in the
two environments, so good performance on the training data does not guarantee safe
navigation on Mars.

Therefore, human demonstrations should be supplemented with training and evaluation in
environments that closely approximate Martian conditions, as well as additional expert feedback
on unfamiliar states. Overall, imitation learning is a reasonable initial approach, but its usefulness
depends on how representative the demonstrations are of the deployment environment.
